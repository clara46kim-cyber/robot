# 로보파크 로봇 탐험대 퀴즈 v4

## 구성

1. 티파(T.Pa): 로봇이란? 로봇의 구성
2. 티마(T.Ma): 로봇의 역사
3. 티피(T.P): 로봇 OX 퀴즈
4. 티나(T.Na): 미래 로봇 상상하기

각 퀴즈는 답을 선택하면 정답 여부와 설명이 표시됩니다.
티나 파트는 자유롭게 로봇 아이디어를 작성하고 결과 카드를 확인하는 활동입니다.

## 실행

```bash
npm install
npm run dev
```

## Vercel 배포

- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`
- Root Directory: 비워두기
