# 로보파크 로봇 탐험대 퀴즈 v5

첫 화면에 아래 네 파트가 정확히 표시됩니다.

1. 티파(T.Pa): 로봇이란? · 로봇의 구성
2. 티마(T.Ma): 로봇의 역사
3. 티피(T.P): 로봇 OX 퀴즈
4. 티나(T.Na): 로봇과 상상하기

## 실행

```bash
npm install
npm run dev
```

## Vercel

- Framework Preset: Vite
- Build Command: npm run build
- Output Directory: dist
- Install Command: npm install
- Root Directory: 비워두기
